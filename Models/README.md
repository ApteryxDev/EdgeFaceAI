# Bundled demo models

StudentAttributes.mlpackage, FastFaceAttributes.mlpackage and OpenCVExpression.mlpackage
are included, preconverted, for the photo/camera quick start. No legacy model is needed.
See THIRD_PARTY_NOTICES.md for provenance and terms. demo-assets.json records file hashes.
Run `python3 Scripts/verify-assets.py` from the repository root to verify all required assets.
